# The Pascal Frontier

**The Pascal Frontier** is Project Dominion Studios' graphic-novel technical
whitepaper series about modern AI inference on NVIDIA Pascal/Volta-era
hardware, evidence-led compatibility engineering, and measured real-world
capability.
